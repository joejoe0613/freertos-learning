# FreeRTOS-learning

A 12-week hands-on FreeRTOS learning project.

## Goals

- Understand FreeRTOS task scheduling
- Learn inter-task communication
- Learn synchronization mechanisms
- Work with interrupts and FreeRTOS
- Understand RTOS memory management
- Practice RTOS debugging
- Build a final multi-task embedded system

## Learning Roadmap

| Week | Topic |
|------|------|
| 1 | Task Basics |
| 2 | Scheduling and Priority |
| 3 | Queue |
| 4 | Semaphore |
| 5 | Mutex |
| 6 | Task Notification and Event Groups |
| 7 | Software Timer |
| 8 | Interrupt and ISR |
| 9 | Memory Management |
| 10 | RTOS Debugging |
| 11 | Mini Project |
| 12 | Final Project |

## Environment

- Linux Mint
- GCC
- Git / GitHub
- FreeRTOS
